# it-support-lab
A practical IT support lab created to document and practice common first-level IT support tasks in Windows environments.

## Areas Covered

- Windows 11 troubleshooting
- Hardware and software diagnostics
- User account and access troubleshooting
- Wi-Fi and network diagnostics
- Basic PowerShell and CMD commands
- MFA and SSO concepts
- Endpoint security checks
- IT asset management
- Incident documentation and escalation

## Troubleshooting Workflow

For a typical support request, I follow a structured process:

1. Identify the user's issue and collect relevant information.
2. Determine whether the problem is related to hardware, software, network, or user access.
3. Reproduce the issue when possible.
4. Check basic configuration and system status.
5. Apply an appropriate solution and test it.
6. Document the solution.
7. Escalate the issue if it requires administrator access or further investigation.
