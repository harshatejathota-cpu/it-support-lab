# First-Level IT Troubleshooting Guide

This guide documents a structured approach to common first-level IT support issues.

## Account Access Issue

1. Confirm the correct username or email.
2. Check whether the account is locked.
3. Verify password and MFA status.
4. Record any error messages.
5. Test whether other services are accessible.
6. Escalate if administrator access is required.

## Wi-Fi / Internet Issue

1. Confirm Wi-Fi is enabled and connected.
2. Check the IP configuration using `ipconfig /all`.
3. Test network connectivity using `ping`.
4. Test DNS resolution using `nslookup`.
5. Determine whether the issue affects one device or multiple users.
6. Escalate if the issue appears to be network infrastructure related.

## Slow Windows Device

1. Check CPU, memory and disk usage in Task Manager.
2. Identify resource-heavy processes.
3. Check available disk space.
4. Check Windows Update status.
5. Restart affected applications when appropriate.
6. Document recurring problems.

## Suspected Phishing Email

1. Do not open suspicious links or attachments.
2. Verify the sender address and domain.
3. Preserve the email for investigation.
4. Report and escalate the incident.
5. If credentials were entered, immediately report the incident for account protection.

## Escalation

An issue should be escalated when it requires elevated permissions, affects multiple users, presents a security risk, or cannot be resolved through standard first-level troubleshooting.
